# 도하랑 여행 지도 🗺️

다녀온 지역을 **색칠**하고, 다녀온 장소에 **스티커**를 붙이는 우리만의 국내 여행 지도입니다.

## 열기
- `travel-map/index.html` 을 브라우저로 열면 바로 동작합니다 (인터넷 연결 필요: d3 라이브러리를 CDN에서 불러옴).
- GitHub Pages 를 켜면 `https://<아이디>.github.io/<저장소>/travel-map/` 주소로 휴대폰에서도 쓸 수 있고,
  휴대폰 브라우저의 "홈 화면에 추가"로 앱처럼 쓸 수 있습니다.

## 사용법
| 모드 | 하는 일 |
| --- | --- |
| 🖍️ 색칠 | 색을 고르고 지역을 누르면 색칠. 같은 색으로 한 번 더 누르면 날짜·메모 입력. 🧽 지우개로 지우기 |
| ⭐ 스티커 | 스티커를 고르고 지도 위 장소를 누르면 장소 이름·날짜·메모와 함께 붙이기. 붙인 스티커는 끌어서 옮기기, 누르면 수정/떼어내기 |

- 스티커를 붙인 지역이 비어 있으면 자동으로 색칠됩니다.
- 제목(“도하랑 여행 지도”)은 눌러서 바꿀 수 있습니다.
- 오른쪽 패널: 시·군·구 달성률, 시·도별 현황(누르면 해당 지역 확대), 날짜순 여행 기록.

## 저장
- 기록은 브라우저(localStorage)에 자동 저장됩니다. **기기마다 따로** 저장되므로,
  다른 기기와 맞추려면 `💾 백업 저장` → 다른 기기에서 `📂 백업 불러오기` 를 쓰세요.
- `📷 이미지 저장` 으로 전체 지도를 PNG 로 저장해 공유할 수 있습니다.

## 지도 데이터
- 통계청 2013 시군구 경계 ([southkorea/southkorea-maps](https://github.com/southkorea/southkorea-maps)).
- 여행용으로 일반구는 시 단위로 합치고(예: 수원시), 청원군은 청주시로, 군위군은 대구로 분류했습니다 (총 229곳).

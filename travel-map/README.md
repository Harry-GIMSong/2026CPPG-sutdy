# 우리가족 국내여행지도 🗺️

다녀온 지역을 **색칠**하고, 다녀온 장소에 **스티커**를 붙이는 우리만의 국내 여행 지도입니다.

## 열기
- `travel-map/index.html` 을 브라우저로 열면 바로 동작합니다 (인터넷 연결 필요: d3 라이브러리와 지도 경계 데이터를 온라인에서 불러옴).
- GitHub Pages 를 켜면 `https://<아이디>.github.io/<저장소>/travel-map/` 주소로 휴대폰에서도 쓸 수 있고,
  휴대폰 브라우저의 "홈 화면에 추가"로 앱처럼 쓸 수 있습니다.

## 휴대폰에 앱처럼 설치
1. 휴대폰 브라우저로 `https://harry-gimsong.github.io/PR/travel-map/` 를 엽니다.
2. **아이폰(Safari)**: 공유 버튼 → "홈 화면에 추가" / **안드로이드(Chrome)**: ⋮ 메뉴 → "홈 화면에 추가" 또는 "앱 설치"
3. 홈 화면의 🗺️ "여행 지도" 아이콘으로 열면 주소창 없이 앱처럼 실행됩니다.

## 사용법
| 모드 | 하는 일 |
| --- | --- |
| 🖍️ 색칠 | **누구와 갔는지**(셋이서·부모님과·가족들과)를 고르고 지역을 누르면 그 색으로 색칠. 색칠만 할 때는 날짜가 비어 있고, 칠한 곳을 다시 눌러 **날짜·메모를 남긴 방문만 여행 기록에** 올라감. 칠한 곳을 누르면 그 지역의 **방문 기록 목록**이 열려 기록마다 동행·날짜·메모를 고치거나 **＋ 또 다녀왔어요**로 새 기록을 더함. 여러 동행과 다녀온 곳은 줄무늬로 표시. ✏️ 편집으로 동행 이름·색 바꾸기/추가. 🧽 지우개로 지우기 |
| ⭐ 스티커 | 스티커를 고르고 지도 위 장소를 누르면 장소 이름·날짜·메모와 함께 붙이기. 붙인 스티커는 끌어서 옮기기, 누르면 수정/떼어내기 |

- 스티커를 붙인 지역이 비어 있으면 자동으로 색칠됩니다.
- 제목(“우리가족 국내여행지도”)은 눌러서 바꿀 수 있습니다.
- 지도를 확대하면 시·군·구 이름이, 전체 화면에서는 시·도 이름이 보입니다.
- 오른쪽 패널: 시·군·구 달성률, 동행별 곳 수, 시·도별 현황(누르면 해당 지역 확대).
- 여행 기록은 최신순으로 3개까지 보이고, **더보기**를 누르면 **연도별** 또는 **지역별(17개 시·도)**로 묶어서 전체를 볼 수 있습니다.

## 저장
- 공유하지 않을 때는 기록이 브라우저(localStorage)에 자동 저장되며 **기기마다 따로** 저장됩니다.
  여러 기기에서 같이 쓰려면 아래 "함께 쓰기"를 설정하세요. `💾 백업 저장`/`📂 백업 불러오기`로 파일을 옮길 수도 있습니다.
- `📷 이미지 저장` 으로 전체 지도를 PNG 로 저장해 공유할 수 있습니다.

## 👨‍👩‍👧 함께 쓰기 (가족과 같은 지도를 실시간으로)
같은 지도를 여러 휴대폰에서 함께 색칠하고 스티커를 붙일 수 있습니다.
기록은 Google **Firebase**(무료 요금제로 충분)에 저장되며, 처음 한 번만 설정하면 됩니다.

### 1. Firebase 프로젝트 만들기 (PC에서 약 5분)
1. https://console.firebase.google.com 에 Google 계정으로 들어가 **프로젝트 추가** (이름 예: `family-travel-map`, 애널리틱스는 꺼도 됨)
2. 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기**
   - 위치: `asia-northeast3 (서울)` / **프로덕션 모드**로 시작
3. Firestore의 **규칙** 탭에 아래 내용을 붙여 넣고 **게시**
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /maps/{room} {
         allow read, write: if room.matches('^[a-z0-9]{20}$');
       }
     }
   }
   ```
4. **프로젝트 설정(⚙️) → 일반 → 내 앱 → 웹(</>)** 으로 앱 등록 → 나오는 `firebaseConfig` 값을 복사

### 2. 설정 넣기
`travel-map/firebase-config.js` 의 `export default null;` 을 복사한 값으로 바꿉니다.
```js
export default {
  apiKey: "AIza...",
  authDomain: "family-travel-map.firebaseapp.com",
  projectId: "family-travel-map",
  appId: "1:1234567890:web:abcdef"
};
```
(이 값은 웹앱에 원래 공개되는 값이라 저장소에 올려도 괜찮습니다.)

### 3. 공유하기
1. 내 휴대폰에서 지도를 열고 **함께 쓰기 → 🔗 함께 쓰는 지도 만들기** (지금까지의 기록이 공유 지도로 옮겨짐)
2. 공유 창이 열리면 카톡 등으로 아내에게 링크 보내기
3. 아내는 **링크를 열고**, 그 화면에서 "홈 화면에 추가"
   - 홈 화면 앱에서 공유 지도가 안 보이면: 함께 쓰기 칸에 받은 링크(또는 20자리 코드)를 넣고 **참여**

- 한쪽에서 고치면 다른 휴대폰에도 바로 반영되고, 두 사람이 동시에 고쳐도 서로 덮어쓰지 않습니다.
- 인터넷이 잠깐 끊겨도 고친 내용은 연결되면 올라갑니다.
- **링크(코드)를 아는 사람은 누구나 지도를 보고 고칠 수 있으니** 가족에게만 보내 주세요.
- "공유 끊기"를 누르면 그 기기는 공유 전의 개인 지도로 돌아갑니다(공유 지도는 그대로 남음).

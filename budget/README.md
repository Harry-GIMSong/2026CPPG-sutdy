# 우리집 가계부 💰

부부가 각자 휴대폰으로 적고, 같은 가계부를 실시간으로 같이 보는 가족 가계부입니다.

## 열기
- GitHub Pages 주소: `https://harry-gimsong.github.io/PR/budget/`
- `budget/index.html` 을 브라우저로 바로 열어도 동작합니다 (이 경우 기록은 그 브라우저에만 저장).

## 휴대폰에 앱처럼 설치
1. 휴대폰 브라우저로 위 주소(또는 아내에게 받은 공유 링크)를 엽니다.
2. **아이폰(Safari)**: 공유 버튼 → "홈 화면에 추가" / **안드로이드(Chrome)**: ⋮ 메뉴 → "홈 화면에 추가" 또는 "앱 설치"
3. 홈 화면의 💰 "가계부" 아이콘으로 열면 주소창 없이 앱처럼 실행됩니다.

## 사용법
| 탭 | 하는 일 |
| --- | --- |
| 🏠 홈 | 이번 달 쓴 돈·들어온 돈·남은 돈, **예산 대비 사용률**과 "남은 기간 하루에 얼마 쓸 수 있는지", 분류별·사람별 지출, 최근 내역 |
| 💳 카드 | 카드마다 **이번 달 결제일에 나갈 카드값**, 이용기간, 누가 얼마 썼는지, 할부 회차, 쓴 내역. 다음 달 예정 금액과 결제수단별 사용액 |
| 📋 내역 | **달력**에 날짜별 지출/수입 합계. 날짜를 누르면 그날 내역만. 지출/수입·사람·분류·메모 검색으로 거르기 |
| 📊 통계 | **월별**: 한 달 요약, 매일 쓴 돈 + 누적 지출 그래프(예산선), 분류별 도넛, 사람별, 최근 6개월, 지난달과 분류별 비교<br>**연도별**: 연간 총수입·총지출·모은 돈·저축률·월평균, 12개월 수입/지출/남은 돈 그래프, 월별 표, 연간 분류별 도넛, 해마다 비교 |
| ⚙️ 설정 | 함께 쓰기, 이 휴대폰 사용자, 한 달 예산·분류별 예산, 고정지출·수입, 분류·구성원 편집, 엑셀(CSV) 내보내기, 백업 |

- 오른쪽 아래 **＋** 버튼으로 기록: 금액(＋1만 같은 빠른 버튼), 분류, 누가, 날짜, 메모. 예전에 쓴 메모를 고르면 그때 분류가 자동으로 골라집니다.
- 기록을 누르면 고치거나 지울 수 있습니다.

## 💳 카드값 (결제일에 합산)
1. **설정 → 카드·결제수단 → ＋ 추가**에서 신용카드를 등록합니다: 이름, 누구 카드인지, **결제일**, **이용기간 마감일**.
   - 결제일을 넣으면 흔한 이용기간이 자동으로 골라집니다(예: 14일 결제 → 말일 마감, 25일 결제 → 11일 마감).
     카드사마다 조금씩 다르니 카드사 앱의 "결제일별 이용기간"과 맞는지 미리보기로 확인하세요.
2. 지출을 적을 때 **누가**와 **결제수단(카드)**을 고르고, 신용카드면 **일시불/할부 개월**을 고릅니다.
   아래에 "11월 14일 결제"처럼 언제 나가는지 바로 보여 줍니다. 할부는 회차마다 다음 달들로 나눠 계산합니다(무이자 기준).
3. 그 카드의 **결제일에 해당 이용기간 사용액이 합산**되어 💳 카드 탭·홈·달력(💳 표시)에 나옵니다.
- **설정 → 홈·통계 집계 기준**: "카드값 나가는 날"(기본, 통장에서 실제 나가는 달 기준) 또는 "카드 쓴 날" 중에서 고릅니다.
  내역 탭과 달력의 날짜별 합계는 언제나 쓴 날 기준입니다.
- 위쪽 `‹ 10월 ›` 로 달을 옮기고(연도별 통계에서는 해를 옮김), 가운데 글자를 누르면 이번 달로 돌아옵니다.
- **고정지출·수입**(월세·관리비·보험·통신비·월급 등)을 등록해 두면 매달 홈 화면에서 "넣기" 한 번으로 그 달 내역에 들어갑니다.
- 그래프는 무료 [Chart.js](https://www.chartjs.org/)로 그립니다. 인터넷이 없을 때는 간단한 막대그림으로 대신 보여 줍니다.

## ✍️ 빠르게 적기
- **📩 카드 문자 붙여넣기**: 카드 승인 문자를 길게 눌러 복사 → 기록 창의 "카드 문자 붙여넣기" → "내용 채우기".
  금액·날짜·가맹점(메모)·할부·카드를 채우고, "승인취소" 문자는 환불로 채웁니다. 카드는 등록한 카드 이름("신한", "현대" 등)이 문자에 있으면 자동으로 고릅니다.
  (웹앱이라 문자를 직접 읽지는 못해요. 예전에 같은 가맹점을 적은 적이 있으면 분류도 따라 골라요.)
- **⭐ 자주 쓰는 내역**: 기록 창의 ⭐ 버튼으로 저장하면 다음부터 기록 창 맨 위에서 한 번에 고릅니다. 세 번 이상 적은 메모도 자동으로 나와요. 설정에서 뺄 수 있어요.
- **📄 복사**: 기록을 열고 "복사"를 누르면 같은 내용으로 오늘 날짜 새 기록을 적습니다.
- **↩️ 환불·취소**: 기록 창 맨 위 "환불·취소"로 적으면 그 달 지출과 카드값(결제일 기준)에서 빠집니다.
- **#태그**: 메모에 `#제주여행`처럼 붙이면 내역에서 태그로 거르고(여러 달 전체), 통계에서 태그별 합계를 봅니다. 자주 쓴 태그는 기록 창에서 눌러 붙일 수 있어요.

## 🔔 알림·새 기록
- 홈 맨 위에 **앱 안 알림**: 한 달 예산 80%·초과, 분류 예산 초과, 카드 실적 미달(실적 기간 끝나기 7일 전부터). ✕로 닫을 수 있어요.
- 함께 쓰는 중이면 상대가 **새로 적거나 고친 기록**이 홈의 "🔔 새 기록"과 빨간 점으로 표시되고, 기록 창에 누가 언제 적고 고쳤는지 나옵니다. "확인했어요"를 누르면 표시가 사라져요.
- **🎯 카드 실적**: 카드를 등록할 때 전월실적 기준(예: 30만원)과 **실적 기간**(매달 1일~말일, 또는 매달 N일~다음 달 N-1일)을 넣으면 💳 카드 탭에 지금 실적 기간의 사용액(환불은 뺌)과 지난 기간 달성 여부가 나옵니다. 신용카드는 처음에 결제 이용기간과 같게 골라져요.

## 📶 인터넷 없이 열기
- 한 번 열어 두면 지하·비행기 모드에서도 앱이 열리고 기록할 수 있어요. 함께 쓰는 가계부에 적은 기록은 휴대폰에 보관했다가 인터넷이 연결되면 자동으로 올라갑니다(위쪽에 "오프라인 · 연결되면 올라가요" 표시).

## 👨‍👩‍👧 함께 쓰기 (아내와 같은 가계부를 실시간으로)
여행 지도와 **같은 Firebase 프로젝트**를 씁니다(`budget/firebase-config.js`). 처음 한 번만 Firestore 규칙에 가계부 칸을 열어 주면 됩니다.

### 1. Firestore 규칙에 가계부 추가 (PC에서 1분)
https://console.firebase.google.com → 여행 지도 프로젝트 → **Firestore Database → 규칙** 탭에서 아래 내용으로 바꾸고 **게시**
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /maps/{room} {
      allow read, write: if room.matches('^[a-z0-9]{20}$');
    }
    match /budgets/{room}/{rest=**} {
      allow read, write: if room.matches('^[a-z0-9]{20}$');
    }
  }
}
```
(이 단계를 빼먹으면 앱의 함께 쓰기 칸에 "Firebase 규칙에 가계부(budgets) 허용이 필요해요"라고 나옵니다.)

### 2. 공유하기
1. 내 휴대폰에서 가계부를 열고 **설정 → 함께 쓰기 → 🔗 함께 쓰는 가계부 만들기** (지금까지의 기록이 공유 가계부로 옮겨짐)
2. 공유 창이 열리면 카톡 등으로 아내에게 링크 보내기
3. 아내는 **링크를 열고**, 그 화면에서 "홈 화면에 추가"
   - 홈 화면 앱에서 공유 가계부가 안 보이면: 설정 → 함께 쓰기 칸에 받은 링크(또는 20자리 코드)를 넣고 **참여**
4. 각자 **설정 → 이 휴대폰 사용자**에서 본인을 고르면 기록할 때 "누가"가 자동으로 선택됩니다.

- 한쪽에서 적으면 다른 휴대폰에도 바로 보이고, 두 사람이 동시에 적어도 서로 덮어쓰지 않습니다
  (기록 하나하나를 따로 저장하고, 달마다 문서를 나눠 오래 써도 느려지지 않습니다).
- **링크(코드)를 아는 사람은 누구나 가계부를 보고 고칠 수 있으니** 가족에게만 보내 주세요.
- "공유 끊기"를 누르면 그 기기는 공유 전의 개인 가계부로 돌아갑니다(공유 가계부는 그대로 남음).

## 저장·백업
- 공유하지 않을 때는 기록이 브라우저(localStorage)에 저장되며 **기기마다 따로** 저장됩니다.
- `📄 엑셀(CSV)` 로 이번 달 또는 전체 내역을 엑셀에서 열 수 있는 파일로 받을 수 있습니다.
- `💾 백업 저장` / `📂 백업 불러오기` 로 전체 가계부를 파일로 옮기거나 되살릴 수 있습니다.

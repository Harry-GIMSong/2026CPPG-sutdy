# 만자천홍 영입 도감 🧵

파이어 엠블렘 만자천홍(일본어판 万紫千紅)의 영입 조건, 주인공(카이·디트리히·세오도라·레다)별 육성 방향,
외전 일정, 카이 편 동물 포획 유인 재료를 정리한 단일 HTML 페이지입니다.

## 열기
- `https://harry-gimsong.github.io/PR/fe-recruit/`
- 휴대폰 브라우저의 "홈 화면에 추가"로 앱처럼 쓸 수 있습니다.

## 저장
서버나 데이터베이스(Firebase)를 쓰지 않는 정적 페이지입니다. 선택한 주인공과 탭만 브라우저(localStorage)에 기억합니다.

## 데이터 수정
`index.html` 안의 `HOME`, `SCOUT`, `LATE`, `GD`, `ROUTE_PLAN`, `ANI`, `BAIT`, `KAI` 배열을 고치면 됩니다.
출처는 페이지의 "최신·출처" 탭에 있습니다. 기준일 2026-10-23.

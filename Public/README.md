# 4주 맨몸 챌린지 💪 / 쉬운 버전 🌸

하루 10~20분, 도구 없이 하는 4주 맨몸 운동 플래너입니다.

- `basic.html` — 기본 버전 (난이도 입문/보통/고급, 하루 약 11~19분)
- `easy.html` — 쉬운 버전 (점프 없는 저충격 루틴, 하루 약 10~15분)
- `index.html` — 폴더 주소로 들어오면 `basic.html`로 넘겨 주는 안내 페이지

## 휴대폰에 앱으로 설치
1. 휴대폰 브라우저로 `https://harry-gimsong.github.io/PR/Public/` (쉬운 버전은 `…/Public/easy.html`)을 엽니다.
2. **아이폰(Safari)**: 공유 버튼 → "홈 화면에 추가" / **안드로이드(Chrome)**: 상단의 📲 버튼 또는 ⋮ 메뉴 → "앱 설치"
3. 홈 화면 아이콘으로 열면 주소창 없이 앱처럼 실행되고, 한 번 열어 두면 **인터넷 없이도** 동작합니다.

> 앱 설치와 오프라인 실행은 GitHub Pages 같은 https 주소에서만 됩니다. 파일을 직접 열면 플래너는 그대로 쓸 수 있지만 설치는 안 됩니다.

## 기능
- 28일 플랜, 운동 타이머(동작 애니메이션, 알림음, 다정한 음성 안내와 3초 카운트다운)
- 🎵 배경 음악: 브라우저에서 실시간으로 만드는 자체 제작 비트(저작권 걱정 없음). 운동 중엔 신나게, 휴식 땐 잔잔하게 바뀌고, 음성 안내가 나올 땐 소리가 작아집니다. 설정 줄이나 운동 화면의 🎵 버튼으로 켜고 끕니다.
- 완료 기록·컨디션 메모, 연속 달성, 배지, 체력 테스트
